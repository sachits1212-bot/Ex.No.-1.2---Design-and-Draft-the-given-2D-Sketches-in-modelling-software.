# Ex.No.-1.2-Design and Draft the given 2D 
## AIM
 To sketch the given drawing with dimensions using fusion 360 tool.
 
## REQUIREMENTS
 1. Autodesk fusion 360
 2. Windows 10
 3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
 4. 2.5 Mbps or faster download; 500 Kbps or faster upload 
 
 ## PROCEDURE
1. Opening the Software and Creating a New Design 
 
Open Autodesk Fusion 360 software on the computer. Select the Part Design option and create a new design file. Set the unit system to millimetres (mm) to ensure that all dimensions are entered according to the given engineering drawing. 
 
 2. Creating a New Sketch  
 
Click on the Create Sketch option in the toolbar and select the XY plane as the sketching plane. The sketch workspace will appear, allowing the required 2D geometry to be drawn accurately.

3. Drawing the Central Circular Profile 
Select the Circle tool and draw the central concentric circles according to the dimensions specified in the reference drawing. Use the appropriate circle diameters to create the inner and outer circular boundaries of the central component. 
4. Drawing the Surrounding Circular Features  
Use the Circle tool to draw the circular holes on the left and right sides and the additional circular features at the top and bottom. Position the circles at the specified distances from the origin and enter the required diameters and radii using the Sketch Dimension tool.

<img width="332" height="567" alt="Screenshot 2026-10-10 131205" src="https://github.com/user-attachments/assets/68218106-3bd0-45f2-bec4-f00e050884d0" />

6. Constructing the Outer Boundary  
Use the Line, Circle, and Arc tools to construct the outer profile of the component. Draw the connecting lines and curved portions between the circular features, ensuring that the shape follows the given engineering drawing. Maintain the correct arrangement of all the outer curves and connecting segments.  
7. Applying Dimensions to the Sketch  
Select the Sketch Dimension tool and specify the required dimensions, including circle diameters, arc radii, distances between centres, and overall spacing. Enter the dimensions shown in the reference drawing to maintain the correct size and proportions of the component.
9. Applying Geometric Constraints  
Apply suitable geometric constraints to maintain the accuracy of the sketch. Use Coincident to join connected elements, Tangent to connect curves smoothly, Concentric to align circles with a common centre, Equal to maintain equal sizes, and Symmetry to create symmetrical features wherever required.

11. Modifying and Refining the Sketch  
Select the Modify menu and use tools such as Trim, Extend, and other available editing commands to remove unwanted portions and refine the geometry. Check the intersections between lines, arcs, and circles to ensure that the outer boundary is properly formed.

 <img width="256" height="338" alt="Screenshot 2026-10-10 131252" src="https://github.com/user-attachments/assets/9572ff15-2dd1-44e7-b317-865b164a377d" />

13. Completing and Verifying the Sketch  
Check the completed sketch against the given reference drawing. Verify all circular features, dimensions, radii, connecting curves, and the overall profile.Correct any errors or unwanted geometry before clicking the Finish Sketch option to complete the 2D sketch.

<img width="320" height="172" alt="Screenshot 2026-10-10 131311" src="https://github.com/user-attachments/assets/9df5db0b-0314-473b-86b2-32aa661c6bf1" />

15. Creating the Engineering Drawing  
After finishing the sketch, select the Drawing option from the workspace menu and choose From Design. In the Create Drawing dialog box, select the appropriate drawing type and configure the drawing settings for the completed design.

<img width="420" height="340" alt="Screenshot 2026-10-10 131329" src="https://github.com/user-attachments/assets/0e222f48-ab9b-4046-be0d-eab8fe0bebb9" />

17. Setting the Drawing Sheet Parameters  
Choose the ISO standard, set the units to millimetres (mm), select an A3 sheet size, and choose the appropriate sheet orientation. Confirm the sheet dimensions and other settings, then click OK to create the engineering drawing sheet.  
18. Placing the Sketch on the Drawing Sheet  
Place the required drawing view on the sheet and adjust its position and scale to fit properly within the drawing area. Ensure that the component is clearly visible and that the drawing is arranged neatly within the sheet border.  
19. Adding Dimensions and Drafting Details  
Add the required dimensions, radius and diameter markings, centre lines, and other necessary annotations to the drawing. Arrange the dimensions clearly without unnecessary overlap and follow the ISO engineering drafting standards specified for the experiment. 
20. Checking and Saving the Final Drawing 
Inspect the completed drawing to verify the geometry, dimensions, annotations, and overall presentation. Ensure that the drawing matches the given reference figure and that all necessary details are included. Finally, save the Fusion 360 design and drawing file for future reference and submission
